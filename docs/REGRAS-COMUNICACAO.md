# Regras de comunicação com o PO (obrigatórias)

Definidas pelo PO em 2026-10-13. Valem para todas as sessões, entregas e agentes (construtor e revisor).

1. **Toda a pergunta ao PO tem exactamente 3 opções de resposta.**
2. **A opção recomendada vem sempre em primeiro lugar**, marcada como *(Recomendado)*, com o motivo numa linha.
3. As outras duas opções são alternativas reais (não "encher"), cada uma com a consequência numa linha.
4. O PO responde escolhendo uma opção (1, 2 ou 3) ou escrevendo outra resposta.
5. Perguntas só para **decisões de negócio ou autorizações**; o que for técnico decide o construtor e regista no ADR.
6. Se algo depender de uma acção do PO, dar instruções passo a passo muito simples.
7. Nunca assumir uma resposta que o PO não deu: sem resposta, a pergunta continua em aberto.

8. **Toda a resposta termina com o próximo passo concreto para o PO (instruções simples, passo a passo) ou com uma pergunta de 3 opções.** Nunca terminar só com um comentário ou um resumo (regra acrescentada pelo PO em 2026-10-22).

Formato:
> **Pergunta?**
> 1. *(Recomendado)* … — porquê.
> 2. … — consequência.
> 3. … — consequência.
